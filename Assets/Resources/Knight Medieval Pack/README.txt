# Medieval Knight Equipment Pack – Stylized 3D Assets

A complete set of medieval knight equipment models, ready to enhance your fantasy or RPG project.

## Included:
-  Knight Sword
-  Knight Shield
-  Medieval Spear
-  Knight Armor Set (static)

## File Formats:
- FBX / OBJ / GLB for each model
- All assets include PBR texture maps (Base Color, Roughness, Metallic, Normal)

## How to Use:
1. Choose the format best suited to your engine.
2. Import the model and textures into Unity, Unreal, Godot, or Blender.
3. Assign the textures to the material in your engine.
4. Customize scale, materials, or combine with animations as needed.
